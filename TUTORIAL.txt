Olivia Letter 信箱使用教程

这是一个 Windows 本地 AI 信箱工具。你写一封信，它会用你配置的 AI 服务生成林离的回信；信件、人设、记忆和 API Key 都保存在你自己的电脑上。

【1. 下载并启动】

1. 打开 最新版本发布页：https://github.com/sron0404/OliviaLetterOverlay/releases/latest。
2. 下载完整包的 OliviaLetterOverlay-1.3.1-win-x64-with-updater.7z.001 和 .002。
3. 把两个分卷放在同一目录，右键 .001 用 7-Zip/NanaZip 解压，不要直接在压缩包里双击运行。
4. 打开解压后的文件夹，双击 OliviaLetterOverlay.exe。

推荐使用 64 位 Windows 10/11。发布包自带运行时，通常不需要另外安装 .NET。

平时只需要双击压缩包根目录的 OliviaLetterOverlay.exe，不需要运行任何脚本。想让信箱在游戏出现时自动弹出，请看压缩包根目录的 脚本说明.txt。

如果想校验下载是否完整，可以核对 SHA256SUMS-v1.3.1.txt 里的哈希值。

如果发布页提供 OliviaLetterUpdater-1.3.1-online-win-x64.exe，也可以只下载并运行这个更新器，它会自动下载升级分卷。

【2. 第一次配置 AI】

启动后点击右上角的圆形“S / 设置”按钮，进入 AI 模型设置。

◆ 方案 A：MiMo

1. 服务类型选择 MiMo 官方接口。
2. 在 MiMo API Key 里粘贴你的 Key。
3. 点击 保存设置。

MiMo 的模型固定为 mimo-v2.5，不需要填写地址。

◆ 方案 B：云端服务商或中转站

1. 在 服务类型 中选择服务商，例如 OpenAI、Anthropic、Google Gemini、DeepSeek、Moonshot Kimi、智谱 GLM、阿里云百炼 Qwen、OpenRouter 等。
2. 程序会自动填入推荐 Base URL；如果服务商给的是专用地址，也可以手动改成它提供的地址。
3. 点击 获取列表，从上游拉取可用模型并选择一个模型。
   - 如果接口不支持模型列表，直接在模型名框里手动填写服务商提供的模型名。
4. 填写该服务商的 API Key。
5. 点击 保存设置。

每个服务类型的 Key 都分开保存，切换服务商时不会互相覆盖。

◆ 方案 C：本地 Ollama

1. 服务类型选择 本地 Ollama。
2. 点击 管理本地模型。
3. 如果还没有安装 Ollama，点击 下载 Ollama；也可以先填写自定义安装目录，再开始安装。
4. 从“选择模型”里选一个适合设备的模型，或填写 Ollama 官方库里的模型名。
5. 点击 下载所选模型，等待下载完成。
6. 点击 使用所选模型，回到设置页后再点 保存设置。

本地模型不需要 API Key，但回信时 Ollama 必须保持运行。

◆ 方案 D：本地 IndexTTS-2.5 朗读

1. 在 AI 模型设置的“信件朗读”区域点击“一键准备”，程序会打开官方部署页并复制命令。
2. 按官方说明安装 Git LFS、uv 和 IndexTTS-2.5 模型；Windows 显存较小时可跳过 DeepSpeed 额外组件。
3. 部署完成后回到设置点击“重新检测”，找到完整引擎后勾选启用并保存。
4. 只有检测到完整引擎时，主界面才显示“朗读”和“重新生成”按钮。

【3. 写信和读回信】

1. 在主界面底部点击 写信。
2. 在信纸里输入想写的内容。
3. 点击 寄出信件。
4. 等待 AI 回复。成功后左侧会出现这一组往来，右侧会同时显示：
   - 上面一张：林离的回信；
   - 下面一张：你寄出的信。

如果发送失败，状态栏会提示原因。草稿和已成功保存的信件不会因为一次请求失败而丢失。

【4. 下载和分享信件】

选中一组信件后，使用右上角：

- 下载：把当前信件图片保存到本机。
- 分享信件：把当前信件图片写入剪贴板，方便粘贴到聊天工具。

【5. 用旧截图调教人设】

如果已有原来的聊天或信件截图，可以提炼成可复用的人设：

1. 进入 AI 模型设置。
2. 点击 信件人设 区域的 分析人设。
3. 左边列表放“我发给她的信”，右边列表放“她回给我的信”。
4. 两侧数量必须相同，并且顺序一一对应：第 1 张对第 1 张，第 2 张对第 2 张。
5. 点击开始分析。分析成功后点击 启用这版人设。

图片可以直接拖进列表。这个功能需要使用支持图片识别的模型；本地纯文字模型可能无法完成 OCR 和人设分析。

【6. 管理记忆】

进入 AI 模型设置，点击 打开记忆库。

- 可以手动补充、修改、删除记忆。
- 点击 分析信箱记忆，让 AI 从已有往来中提炼记忆。
- 点击 保存记忆 后才会生效。

记忆用于让后续回信更连续，但不应把真实敏感信息写进去，除非你确实希望 AI 在回信中引用它。

【7. 主动来信】

进入 AI 模型设置，找到 主动来信：

- 填 0 表示关闭。
- 填 10 到更大数字表示每隔多少分钟尝试生成一封主动来信。

例如填 30 后，程序运行期间约每 30 分钟可能收到一封新信。关闭程序后不会在后台生成。

【8. 和游戏一起启动】

最简单的方式是完全退出游戏后，打开 installer 文件夹并双击 Install.cmd。它会把最新版程序安装到当前 Windows 用户目录、创建开机伴随启动快捷方式，并在能找到默认 Steam 游戏目录时自动安装启动器包装。

之后正常从 Steam 或原来的游戏入口启动游戏；信箱会先在后台等待，检测到 Olivia 游戏窗口后自动显示。游戏关闭后会隐藏并继续等待。

如果只想这一次伴随游戏、不想安装，双击压缩包根目录的 StartOliviaLetterWatch.cmd，保持它运行后再启动游戏即可。

每个脚本的用途、如何停止伴随、如何还原游戏启动器，都写在压缩包根目录的 脚本说明.txt 里。

【9. 备份、移动和删除数据】

数据保存在：

    %LOCALAPPDATA%\OliviaLetterOverlay

包括信件、人设、记忆和 AI 设置。备份时复制整个文件夹即可。卸载或删除程序本体不会自动删除这些数据；想彻底清除，需要手动删除这个文件夹。

【10. 常见问题】

◆ 提示“未检测到 API Key”

检查服务类型是否选对了。不同服务类型的 Key 分开保存；例如 DeepSeek 的 Key 不会被 OpenAI 或 MiMo 复用。

◆ 获取模型列表失败

先确认 API Key、Base URL 和网络是否正确。有些中转站或服务商没有实现标准模型列表接口，这时直接手动填写模型名即可。

◆ 回复很慢或超时

云端模型受服务商速度影响；本地模型受显卡、内存和模型大小影响。设备较弱时优先选更小的模型。

◆ 图片分析失败

图片太模糊、内容太小，或当前模型不支持视觉识别，都可能导致失败。建议换更清晰的截图，或切换到支持识图的云端模型。

◆ 界面显示不正常

先关闭程序，重新从解压目录运行新版 OliviaLetterOverlay.exe。不要在压缩包内直接运行。

【安全提醒】

API Key 只保存在当前 Windows 用户配置中，项目源码和发布包不包含你的 Key。请只从你信任的官方或服务商页面获取 Key；不要把已填好的本机配置目录直接分享给别人。

这是独立本地工具，不是官方客户端，也不代表原作品作者或发行方。

# Olivia Letter 信箱

一个面向 Windows 的本地 AI 信箱应用。它提供书信式对话体验，支持 MiMo、OpenAI 兼容接口和本地 Ollama；信件、记忆与人设数据默认保存在本机。

> 本项目使用来自 [1Dreamer666/olivia-lin](https://github.com/1Dreamer666/olivia-lin) 的人设素材；该项目采用 AGPL-3.0 许可，因此本项目也按 AGPL-3.0 发布，详见 `THIRD_PARTY_NOTICES.md`。

完整流程、模型配置、人设分析、记忆、主动来信和常见问题见 [使用教程](TUTORIAL.md)；纯文本版见 [TUTORIAL.txt](TUTORIAL.txt)。

## 功能

- 书信式聊天：来信与回信渲染为可下载/分享的信纸图片。
- 多模型接入：MiMo、常见云端服务商、OpenAI 兼容接口/中转站、本地 Ollama。内置 OpenAI、Anthropic、Google Gemini、DeepSeek、Moonshot Kimi、智谱 GLM、阿里云百炼 Qwen、火山方舟、xAI Grok、Mistral、Groq、OpenRouter、SiliconFlow、Together AI 预设。
- 本地模型管理：可下载和选择适合设备的 Ollama 模型。
- 人设分析：上传参考聊天图片，提取人设、记忆和参考信件。
- 记忆与主动来信：支持长期记忆，主动来信间隔最低 10 分钟。
- 角色切换：右上角可新建或切换角色，各自保留独立的信箱、人设、记忆和主动来信设置。
- 诊断日志：设置页和本地模型页均可导出脱敏日志，方便排查接口错误和下载停滞。
- 游戏伴随启动：开机后台静默等待，检测到 Olivia 游戏主窗口后自动打开信箱。
- 信件朗读（可选）：用本地 IndexTTS-2.5 引擎把当前回信合成为 Olivia 的声音并播放，同一封信只合成一次；也可在设置里开启「收到新信后自动朗读」。
- 个人照片邮票：发信信纸保留本地人像邮票装饰。

## 下载与运行

1. 从 Releases 下载 `OliviaLetterOverlay-1.1-win-x64.zip`。
2. 解压到任意目录。
3. 双击 `OliviaLetterOverlay.exe`。

推荐 64 位 Windows 10/11。发布包为 self-contained，通常无需额外安装 .NET 运行时。

## AI 配置

点击右上角设置按钮：

- **MiMo**：填写 API Key，模型固定为 `mimo-v2.5`。
- **云端服务商 / 中转站**：选择服务类型后自动填入推荐 Base URL；按需修改地址、选择或填写模型名，并填写该服务的 API Key。不同服务类型的 Key 分开保存。
- **Ollama**：填写本地服务地址和模型名，默认 `http://127.0.0.1:11434`。

API Key 保存在当前 Windows 用户本地配置中，源码和发布包不包含密钥。

## 回信完整性

回信不再按 260 字截断，也不在默认提示词中强制固定字数；纸面写满后按实际字体排版续到下一页。阅读区保持一张固定信纸照片，边框、纸张背景和日期始终钉在原位，滚轮只让独立的文字层上下移动，不会让两张照片来回滚动。右下角按钮会打开真正的全屏看信窗口，Esc 或右上角按钮退出。下载会保存全部回信页并标注页号，分享图片按顺序包含所有页。原先已被截断并保存的文字无法凭空恢复；仅因旧版排版隐藏的文字，在新版打开后即可显示。

普通回信和主动来信的接口生成预算为 4096 token，不是 4096 字，也不会据此再次裁剪正文。DeepSeek 通道显式关闭默认思考；智谱保留低推理强度，不向要求思考的模型发送禁用参数。接口仍可能受模型或中转服务的限制；检测到长度截断、未完成响应、仅思考无正文或返回格式异常时，会显示具体原因，不会把半封回信当作完整回信保存，也不会自动重试产生额外调用。

## 角色与独立记忆

点击信箱右上角的“角色：名称 ▾”，选择已有角色并点击“切换角色”，或填写新角色名、可选的人设说明，点击“新建并切换”。

左侧每条历史聊天记录（包括内置“你好”“欢迎来到信箱”）可右键选择“重命名”，或选中后点击右侧标题旁的小铅笔。输入 1–40 字后点击“保存”或按 Enter，按 Esc 或点击“取消”放弃修改。名称按角色和记录分别保存在 `letter-titles.json`，重启后保留；不修改“我的信箱”总标题、聊天正文、人设或记忆。底部“今天还有 67 封书信”是固定显示文案，不是实际发送配额，也不会随寄信扣减。

- 每个角色独立保存人设、长期记忆、参考信件、历史往来和主动来信设置；新角色从空白信箱开始。
- AI 服务地址、模型和 API Key 共用。切换角色不会改动 API 配置。
- 原有数据仍在原目录，归属“林离”，不会迁移、复制给新角色或被清空。
- 请求发出时会固定角色；切换期间晚到的回信或分析结果仍归原角色，不会写入新角色。

这里的隔离是应用数据与发送上下文的隔离，不是模型训练；无法保证模型绝不自行猜测或编造事实。

## 导出诊断日志

遇到接口错误或模型下载卡住时，在“AI 模型设置”或本地模型窗口点击“导出诊断日志”，保存 `.txt` 文件即可分享排查。下载仍在进行时也能导出。

日志包含版本、服务与模型、HTTP 状态、耗时、磁盘空间、回复结束原因及正文/思考字符数，以及下载字节数、无进展时长和下载错误；应用记录有大小限制，并附带本机 Ollama 日志中最近的下载相关片段。不会附带信件、记忆、人设、请求正文或完整响应正文，API Key、网址参数和当前用户目录会脱敏。

新诊断记录从运行新版后开始产生；无法还原旧版未记录的接口请求。导出功能用于定位问题，不会自动重启下载或保证网络恢复。

## 游戏伴随启动

程序支持：

```text
OliviaLetterOverlay.exe --watch
```

发布包已附带 `Olivia Letter 游戏伴随启动` 快捷方式思路：将带 `--watch` 参数的快捷方式放入 Windows 启动文件夹后，程序开机静默运行；检测到 `Olivia` 游戏主窗口时自动显示信箱。

## 信件朗读

在「AI 模型设置 → 信件朗读」勾选启用后，回信页会出现「朗读」按钮：点击后调用本机 IndexTTS-2.5 引擎（NVIDIA 显卡 BF16 分阶段卸载推理）合成整封回信的语音并播放（自动去掉信末署名）；合成期间再点一次可取消，播放期间再点一次可停止。已合成的语音自动保存在本机，重启应用后同一封信无需重新合成；不满意这版语音可点「重新生成」换一个随机种子重合成一版。

完整的部署步骤和 1.0.1 → 1.1 对比见 [`INDEXTTS-GUIDE.md`](INDEXTTS-GUIDE.md)。

- 首次使用点「一键准备」会打开 [IndexTTS 官方仓库](https://github.com/index-tts/index-tts) 并复制部署命令；部署完成后点「重新检测」，程序会自动关联已安装目录。
- 官方 Windows 部署流程：安装 Git LFS、`uv`，克隆仓库后运行 `uv sync --all-extras`，再执行 `hf download IndexTeam/IndexTTS-2.5 --local-dir=checkpoints`；Windows 显存较小时可按官方说明跳过 DeepSpeed 额外组件。
- 引擎目录默认 `D:\codex work\IndexTTS-2.5`（需包含 `.venv\Scripts\python.exe`、`local_tools\olivia_tts_worker.py` 和 `reference\lv_0_reference_6.8-22.1.wav`），可在设置中修改。
- 点朗读会直接用显卡合成；若显存被游戏等程序占用导致失败，会明确提示并可在弹窗中当场改选 CPU 慢速生成（整封约 5–10 分钟）。
- 首次合成整封回信约 35–60 秒，按钮会显示进度；切走信件会自动取消或停止。
- 「收到新信后自动朗读」默认关闭；开启后新来信会在后台合成并自动播放，失败只记录日志不打扰使用。
- 朗读音频缓存在各角色数据目录的 `tts/` 子目录下；语音模型不出本机，文本不会上传。

## 数据位置

用户数据保存在：

```text
%LOCALAPPDATA%\OliviaLetterOverlay
```

包括信件、人设、记忆和 AI 提供商设置。卸载程序不会自动删除它们；需要彻底清除时请手动备份或删除该目录。

`characters.json` 保存角色列表和当前选择；新角色数据位于 `characters/<角色ID>/`，诊断记录位于 `logs/`。默认“林离”继续使用原有根目录数据文件。

## 从源码构建

需要 Windows 和 .NET 10 SDK：

```powershell
dotnet build .\OliviaLetterOverlay.csproj -c Release
dotnet publish .\OliviaLetterOverlay.csproj -c Release -r win-x64 --self-contained true /p:PublishSingleFile=true
```

回归验证使用虚构聊天和本机模拟接口，不调用收费模型，也不读取或改写真实用户信箱：

```powershell
dotnet run --project .\tests\OliviaLetterOverlay.Tests\OliviaLetterOverlay.Tests.csproj -c Release
```
